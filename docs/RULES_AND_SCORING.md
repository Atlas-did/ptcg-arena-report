# 赛制与评分（据官方规则页整理）

> 来源：<http://115.159.47.81/rules>（2026-10-28 读取）。
> 本文只摘录会影响策略与报告解读的条目；以官方页面为准。

## 1. 对局与轮次

- 每轮为**单循环赛**，任意两队对战 **1 局**。
- B 榜 28 支队伍 → 每队每轮 **27 局**；我们 58 轮共 **1566 局**（1286 胜 277 负 3 平）。
- 对战默认每 1 小时自动触发一轮（后台可调）；平台固定随机种子，保证可复现。

## 2. 积分

- 每轮按**名次**赋分：第 1 名 100 分，最后一名 10 分，中间按本轮实际参赛队数线性递减。
- **不是按胜场直接换算积分**。胜场决定名次，名次决定积分。
- 仅实际参赛（提交有效 Agent 并参加该轮）的队伍得分；B 榜总积分 = 各轮积分之和。
- 同分处理：比较最近一轮名次，依次往前；仍相同按团队名字典序。

## 3. 提交物

```
submission.tar.gz
├── main.py    # def agent(obs_dict: dict) -> list[int]
└── deck.csv   # 恰好 60 行，每行一个 cardId
```

- 开局选牌阶段平台不调用 `agent`，直接用 `deck.csv` 组牌。
- 返回值必须是合法 `option` 下标，长度满足 `minCount ≤ len ≤ maxCount`，不能重复。
- 非法下标、重复下标、错误长度、崩溃、超时均判负。

## 4. 组牌合法性

- 恰好 60 行整数，所有 id 必须在 `cards.csv` 卡池内。
- 至少 1 张**真正的基础宝可梦**（`cardType=0` 且 `basic=1`；化石不算）。
- 同名卡 ≤ 4 张（按卡名统计，不按 id）；基础能量不受限。
- **ACE SPEC 全牌组 ≤ 1 张**（按 `aceSpec` 标记，即使卡名不同）。
- 平台不额外限制能量数量，也没有禁用卡。

## 5. 胜负

满足任一即结束：

1. 一方取完 6 张奖赏卡 → 该方胜；
2. 一方场上没有任何宝可梦（出战区与备战区均为空）→ 对方胜；
3. 一方回合开始需抽牌但牌库已空 → 该方负。

结果在 `current.result` 读取（-1 进行中，0/1 为玩家 0/1 胜）。

## 6. 沙箱与超时

- 每个 Agent 独立沙箱：内存 2 GB、CPU 2 核、进程数上限 100。
- 网络禁用、文件系统只读挂载；每局固定随机种子。
- 单步决策默认 **100 ms**，整局默认 **10 分钟**；超时判负。
- `import` / 初始化在对局开始前执行，不计入单步限时。
